# whatsub?

## 구현 기능 설명

* Gmail API를 활용하여 사용자의 결제 이메일 데이터를 수집
* 구독 관련 키워드를 분석하여 OTT 및 디지털 구독 서비스 자동 분류
* TMDB API를 활용하여 영화 및 드라마 메타데이터 저장
* Streaming Availability API를 활용하여 콘텐츠 제공 OTT 조회
* Django REST Framework 기반 REST API 서버 구현
* Serializer를 활용한 JSON 응답 반환
* Postman을 활용한 API 테스트 진행

---

## 학습 내용

* Django REST Framework를 활용한 API 서버 구현 방법
* 외부 API 연동 및 데이터 저장 방식
* Serializer를 활용한 JSON 직렬화
* Gmail API 및 TMDB API 사용 방법
* 환경변수(.env)를 활용한 API KEY 관리
* Postman을 활용한 API 테스트 방법

---

## 느낀 점

이번 프로젝트를 통해 단순한 데이터 출력이 아닌 실제 REST API 서버 구조를 경험할 수 있었다.
특히 여러 외부 API를 연결하고 데이터를 가공하는 과정에서 API 구조와 JSON 데이터 처리 방식에 대해 많이 학습할 수 있었다.
또한 Gmail 데이터를 기반으로 구독 서비스를 분석하는 기능을 구현하면서 실제 서비스 형태로 확장할 수 있는 가능성을 느낄 수 있었다.
